### Milestone F local arm64 installer

Built with `bun run --cwd apps/desktop bundle --ci --bundles app,dmg`. The DMG is `apps/desktop/src-tauri/target/release/bundle/dmg/Slide Workspaces_0.1.0_aarch64.dmg`: **324,613,039 bytes (309.58 MiB)**, SHA-256 `f41403326fde13eccdf2e74012f2e2c9388afb76a1cf338b1b285b62640a1007`. `hdiutil verify` reported a valid checksum and the app passed deep strict signature verification. The build is ad hoc signed, with no Team ID or notarization. The [installed screenshots](acceptance.md#milestone-f-installed-macos-arm64) predate a Windows-only OS-version formatting fix.

### Physical Intel smoke test

On the intended physical Intel machine (including any Hackintosh configuration), record OS and host architecture. Inspect the mounted app executable, bundled Chromium executable, Chromium helpers and their native frameworks with `file` and `lipo -archs`; verify each required Mach-O component has an x86_64 slice. Copy the app to Applications, launch natively without translation, and verify a normal browser window, two independent fixture logins, quit/reopen, and the Support report. Record renderer or missing-framework failures without disabling OS protections. A CI cross-check or translated run does not substitute for this check.
